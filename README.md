## 실행
이 저장소의 index.html과 final 폴더를 같은 위치에 둡니다. 별도 빌드나 패키지 설치가 필요 없습니다.
`python -m http.server 8000` 실행 후 http://localhost:8000 에 접속합니다.

## 기능
- PNG/JPEG 이미지, 문구, 비율(1:1·4:5·9:16), 글자 크기·위치·사진 크기 편집 및 PNG 저장
- 사용자 템플릿 생성·불러오기·수정·삭제와 브라우저 저장소 유지
- 템플릿 JSON 내보내기·가져오기, 형식 오류·중복 ID 거부, 가져오기 전 교체 확인
- 서로 다른 소재와 비율의 최종 PNG 3장

## 재현·통과 확인
어디로 가나요: https://aleph-card-studio-20260930.jwonnlee00.chatgpt.site/
무엇을 하나요(3단계 이내):
1) 문구·비율을 편집하고 이름을 달리해 템플릿 3개를 저장한 뒤 JSON 내보내기를 누릅니다.
2) 다른 브라우저 또는 새 시크릿 창에서 같은 사이트를 열어 JSON을 가져오고, 불러오기·수정·삭제·새로고침을 확인합니다.
3) 편집한 카드와 하단 완성 이미지 3장의 PNG를 저장해 열어 봅니다.
무엇이 보이면 통과: JSON에서 이름·문구·비율·ID가 복원되고, 수정·삭제 결과가 새로고침 뒤에도 유지되며 PNG 3장이 각각 1080×1350, 1080×1080, 1080×1920으로 열립니다. 잘못된 JSON은 거부하고 기존 템플릿을 유지합니다.
안 될 때: 사이트를 새로고침하고 PNG 준비 메시지를 기다립니다. 다운로드가 안 보이면 브라우저 다운로드 목록과 사이트 다운로드 권한을 확인합니다. JSON 오류가 나면 원본 내보내기 파일로 다시 시도합니다. 시크릿 창 데이터는 창을 모두 닫으면 사라질 수 있으므로 먼저 JSON으로 백업합니다.

## AI와 내 판단 3줄
AI에게 맡긴 일: 이미지 편집·PNG 저장·템플릿 관리·JSON 이동 기능 구현과 오류 수정, 검증 및 소스 공개를 맡겼다.
내가 판단한 일: 문구와 이미지 소재·출처를 정하고, 극단 입력을 직접 시험하며 실제 PNG 다운로드 여부를 확인했다.
AI 말을 안 들은 일: 새 탭에서 이미지를 수동 저장하라는 대안을 그대로 받아들이지 않고, 버튼으로 저장되도록 수정을 요청했다.
